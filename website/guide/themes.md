# Themes and reading

MD View ships nine theme variants: GitHub Light, GitHub Dark, One Dark, Dracula, and the
corresponding light/dark pairs. The reading view uses the same token system as the editor, so
selection, links, code, tables, alerts, and media share the active palette.

## Reading controls

**Settings → Reading** controls:

- A 5–40% margin slider for the reading column.
- Independent sizes for body text, headings, code, tables, and equations.
- The preview's GitHub 16 px scale is the default; changing the body size rescales the other
  reading controls proportionally.

![Reading settings](/images/settings.png)

## Editor controls

**Settings → Editor** controls the monospace size, line height, scroll-beyond-last-line behavior,
indent guides, whitespace visibility, wrap, line numbers, and split-scroll synchronization.

## Appearance and language

**Settings → Appearance** selects the theme, follows the system light/dark preference, changes the
UI zoom, and switches the interface between English, Spanish, and a pseudo-locale used for layout
testing.

## Accessibility and scaling

The app supports 0.8–2.0 UI zoom, 2× rasterized icons, keyboard menus via F10/Alt, and AccessKit
announcements for the editor's role, value, and selection. The 2× snapshots cover the title bar and
sidebar so HiDPI layouts stay aligned.
